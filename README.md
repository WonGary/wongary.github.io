# 万智翔的学术主页 | Zhixiang Wan

[访问主页 / Academic homepage](https://wongary.github.io/) · [中文简历（PDF）](https://wongary.github.io/assets/Zhixiang_Wan_CV_zh.pdf) · [English CV (PDF)](https://wongary.github.io/assets/Zhixiang_Wan_CV.pdf)

我在北京大学大气与海洋科学系读博，用气候模式研究火星上的沙尘和水冰云，以及重力随纬度变化对早期地球气候的影响。我也用模拟的 JWST 凌星光谱，检验系外行星晨昏两侧的温差是否会被误判为大气成分差异。

I'm a PhD student in the Department of Atmospheric and Oceanic Sciences at Peking University. I use climate models to study dust and water-ice clouds on Mars and how variations in gravity with latitude affect early Earth's climate. I also use simulated JWST transit spectra to test whether a temperature difference between an exoplanet's morning and evening limbs can look like a difference in atmospheric composition.

## 本地预览 / Local preview

在仓库根目录运行以下命令。Run this command from the repository root.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

[打开本地预览 / Open the local preview](http://127.0.0.1:8000/)

## 编辑主页 / Editing the site

英文正文在 `index.html`，对应的中文在 `script.js`。两处用相同的 `data-i18n` 键关联。页面布局和配色在 `styles.css`。

Edit the English text in `index.html` and its Chinese translation in `script.js`, using the same `data-i18n` key for each pair. The layout and colors are in `styles.css`.
